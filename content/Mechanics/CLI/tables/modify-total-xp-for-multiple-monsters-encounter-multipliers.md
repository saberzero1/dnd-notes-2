*Source: Dungeon Master's Guide p. 82. Available in the Basic Rules (2014)* 

**Encounter Multipliers**

| Number of Monsters | Multiplier |
|--------------------|------------|
| 1 | ×1 |
| 2 | ×1.5 |
| 3-6 | ×2 |
| 7-10 | ×2.5 |
| 11-14 | ×3 |
