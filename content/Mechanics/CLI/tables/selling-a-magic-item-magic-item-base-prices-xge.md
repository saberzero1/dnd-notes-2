# Selling a Magic Item; Magic Item Base Prices
*Source: Xanathar's Guide to Everything p. 133* 

**Magic Item Base Prices**

| Rarity | Base Price* |
|--------|-------------|
| Common | 100 gp |
| Uncommon | 400 gp |
| Rare | 4,000 gp |
| Very rare | 40,000 gp |
| Legendary | 200,000 gp |
^magic-item-base-prices

*Halved for a consumable item like a potion or scroll
